JF APPS — FINANCES V1.12.6
CORRECTIF NAVIGATION MENSUELLE DU BUDGET
31 août 2026

PROBLÈME CORRIGÉ
----------------
Dans V1.12.5, le mois interne changeait bien au clic sur les flèches du Budget,
mais l'écran visible pouvait rester sur l'ancien mois jusqu'à ce que l'utilisateur
quitte l'onglet puis y revienne.

CAUSE
-----
La vue Budget mélangeait encore deux mécanismes NiceGUI :
- un conteneur externe budget_box vidé/reconstruit manuellement;
- des mécanismes refreshable utilisés ailleurs dans Finances.

Le correctif V1.12.5 avait changé l'appel de rafraîchissement sans éliminer ce
mélange, ce qui n'était donc pas suffisant.

CORRECTION V1.12.6
------------------
- suppression du conteneur externe budget_box;
- render_budget devient lui-même @ui.refreshable;
- les flèches modifient month_state puis appellent render_budget.refresh();
- le tri et les autres actions du Budget utilisent le même mécanisme;
- refresh_all utilise aussi render_budget.refresh();
- le Tableau demeure synchronisé avec le même month_state.

Ainsi, un clic sur mois précédent/suivant doit immédiatement modifier :
- le nom du mois;
- Revenus/Dépenses fixes;
- Reste mensuel et Reste par paie;
- Disponible ce mois et nombre de paies;
- sections Actives / À venir / Archives;
- Prévisions.

FICHIERS À REMPLACER
--------------------
- finances.py

Les fichiers finances_data.py et finances_shared_loans.py sont inclus dans le

------------

2. Commit changes.

4. Faire Ctrl+F5 sur ordinateur après le redéploiement.
5. Vérifier que Finances affiche V1.12.6.
