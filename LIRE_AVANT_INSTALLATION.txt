JF APPS — CORRECTIF LISTE D’ÉPICERIE V1.1.1

PROBLÈME CORRIGÉ

Le service pouvait s’arrêter avec le message :

The parent slot of Timer(...) has been deleted.

Deux minuteries NiceGUI pouvaient encore tenter d’agir après la fermeture
ou le remplacement de leur page :

- l’actualisation automatique du Mode courses;
- la disparition automatique de la carte Annuler dans Besoins.

CORRECTION

Les deux ui.timer ont été retirés.

Le Mode courses utilise maintenant une tâche contrôlée qui :
- vérifie que la page existe encore avant chaque actualisation;
- s’arrête dès que la page est quittée;
- intercepte toute erreur de contexte sans arrêter le service;
- conserve l’actualisation automatique toutes les cinq secondes;
- conserve le bouton Actualiser manuel.

La carte Annuler dans Besoins utilise aussi une tâche contrôlée :
- elle cesse sans erreur lorsque la page est quittée;
- le bouton Annuler vérifie maintenant que le délai est encore valide;
- une ancienne carte ne peut plus restaurer un item après expiration.

INSTALLATION

1. Ouvrir le dépôt GitHub.
2. Choisir Add file > Upload files.
3. Déposer les quatre fichiers ensemble.
4. Faire Commit changes.
5. Attendre le redémarrage Canner.
6. Recharger le site avec Ctrl+F5.
7. Sur téléphone, fermer puis rouvrir la PWA.

TESTS RECOMMANDÉS

1. Ouvrir Besoins.
2. Retirer un item puis naviguer immédiatement vers une autre page.
3. Attendre au moins 10 secondes.
4. Vérifier que le service reste actif.
5. Ouvrir Mode courses.
6. Le laisser ouvert pendant au moins 20 secondes.
7. Revenir au Portail ou à Items.
8. Attendre encore au moins 10 secondes.
9. Vérifier les journaux Canner.
10. Confirmer qu’aucun message « parent slot of Timer » ne réapparaît.
