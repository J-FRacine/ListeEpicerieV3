JF APPS — FINANCES V1.6.2 — CORRECTIF DE DÉMARRAGE
===================================================

POURQUOI CE CORRECTIF
---------------------
La V1.6.1 a pu faire échouer l’activation Canner avant que le serveur HTTP
commence à écouter. Le message Canner ne contenait pas le traceback Python.

Ce correctif rend les nouvelles initialisations Finances/Web Push non
bloquantes pour le Portail :
- le Portail peut démarrer même si une migration Finances rencontre un problème;
- Finances réessaie automatiquement sa mise à niveau lors de son ouverture;
- si cette seconde tentative échoue, l’erreur technique exacte est affichée
  dans l’écran Finances et imprimée dans le journal;
- la création de la table de suivi des rappels Finances est faite dans la
  tâche de fond après le démarrage HTTP;
- le lien Budget–Récurrence reste validé dans l’application et n’ajoute plus
  une contrainte SQL facultative susceptible de bloquer le démarrage.

FONCTIONS CONSERVÉES
--------------------
Toutes les fonctions V1.6.1 restent présentes :
- Compte et vue annuelle;
- Budget mensuel / aux deux semaines;
- Hors budget;
- lien Budget ↔ Récurrence;
- Programmée dans le compte bancaire;
- rappel Web Push le jour prévu;
- canaux Finances et Journal de pression indépendants.

--------------------------------------

- blood_pressure.py

Aucun script SQL manuel.

INSTALLATION
------------
1. Dans GitHub, remplacer les 7 fichiers ci-dessus par ceux du paquet.
2. Commit changes.
3. Laisser Canner redéployer.
4. Vérifier d’abord que le Portail s’ouvre.
5. Ouvrir ensuite Finances.
6. Si Finances montre une carte « mise à niveau de la base impossible »,
   copier exactement l’erreur affichée et la transmettre à ChatGPT.

IMPORTANT
---------
Ne pas supprimer la base de données et ne pas effacer les transactions.
Le correctif est conçu pour fonctionner même si le déploiement V1.6.1 a
réussi à créer certaines colonnes avant de s’arrêter.
