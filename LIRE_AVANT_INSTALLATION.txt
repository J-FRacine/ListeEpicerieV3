NOUVEAUTÉS DE LA V1.2.0

1. MODES DE PAIEMENT
Valeurs initiales :
- MC Canadian Tire
- MC PC
- Visa Desjardins
- Direct

Chaque utilisateur peut :
- ajouter un mode de paiement;
- le renommer;
- l’activer ou le désactiver;
- le déplacer vers le haut ou le bas;
- l’attribuer à une transaction;
- le mémoriser dans une transaction récurrente.

La gestion se trouve dans :
Finances > Organisation > Modes de paiement.

2. CONCILIATION
Chaque transaction possède maintenant un statut distinct :
- À concilier;
- Conciliée.

Une date de conciliation facultative peut être enregistrée.

Dans l’historique :
- le bouton avec deux crochets permet de marquer une transaction conciliée;
- le bouton Annuler permet de la remettre à concilier;
- les filtres permettent de choisir un mode de paiement
  et un statut de conciliation.

3. RÉSUMÉ MENSUEL DE CONCILIATION
Dans Tableau, une section par mode de paiement affiche :
- les dépenses;
- les revenus;
- les dépenses à concilier;
- les revenus à concilier;
- le nombre de transactions à concilier.

Les transactions sans mode de paiement apparaissent sous :
« Sans mode de paiement ».

4. HISTORIQUE PLUS LISIBLE
Sur grand écran :
- dépenses dans la colonne de gauche;
- revenus dans la colonne de droite.

Sur téléphone :
- les deux sections sont empilées.

Tous les montants sont justifiés à droite.
Les descriptions et autres textes restent alignés à gauche.

5. KPI MENSUELS
Dans Tableau :
- KPI des dépenses par catégorie;
- KPI des dépenses par étiquette;
- montant et part mensuelle pour les catégories.

6. IMPORTATION ET EXPORTATION
Les CSV et JSON JF Apps peuvent maintenant contenir :
- Mode de paiement;
- Conciliation;
- Date de conciliation.

Lors d’une importation, les modes de paiement manquants
peuvent être créés automatiquement.

Les fichiers Spendee demeurent compatibles.
Comme Spendee ne fournit pas le mode de paiement dans le fichier
utilisé, ces transactions sont importées sans mode de paiement
et avec le statut « À concilier ».

MIGRATION AUTOMATIQUE DE LA BASE DE DONNÉES
Au prochain démarrage, l’application :
- crée la table finance_payment_methods;
- ajoute payment_method_id aux transactions et récurrences;
- ajoute reconciliation_status et reconciliation_date
  aux transactions;
- crée les index et contraintes nécessaires.

Aucun script SQL manuel n’est requis.

DONNÉES EXISTANTES
Les transactions déjà présentes sont conservées.
Elles recevront automatiquement :
- aucun mode de paiement;
- le statut À concilier;
- aucune date de conciliation.

INSTALLATION
1. Ouvrir le dépôt GitHub.
2. Choisir Add file > Upload files.
3. Déposer les quatre fichiers Python ensemble.
4. Faire Commit changes.
5. Attendre le déploiement Canner.
6. Faire Ctrl+F5 ou fermer et rouvrir la PWA.
7. Vérifier que Finances affiche V1.2.0.
