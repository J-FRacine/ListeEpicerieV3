JF APPS — FINANCES V1.12.5
Correctif : navigation mensuelle du Budget
Date : 31 août 2026

PROBLÈME CORRIGÉ
----------------
Dans Budget, cliquer sur les flèches précédent/suivant changeait bien le mois
interne, mais l’écran ne se redessinait pas immédiatement. Il fallait quitter
l’onglet Budget puis y revenir pour voir le bon mois et les bons calculs.

CAUSE
-----
Le contenu Budget est construit dans un conteneur dédié (budget_box), alors que
la navigation utilisait un refresh() de fonction décorée. L’état était donc mis
à jour, mais le conteneur visible n’était pas reconstruit de façon fiable.

CORRECTION V1.12.5
-----------------
- le changement de mois déclenche maintenant directement le rendu du conteneur
  Budget;
- le nom du mois, les KPI, le nombre de paies, les sections Actives/À venir/
  Archives et les Prévisions changent immédiatement;
- le Tableau demeure synchronisé avec le mois sélectionné;
- aucun changement de données ni de schéma.

FICHIERS À REMPLACER
--------------------
- finances.py
- app_versions.py
- manual.py

Les fichiers finances_data.py et finances_shared_loans.py sont inclus dans le
paquet complet mais sont inchangés par rapport à V1.12.4.

INSTALLATION
------------
1. Remplacer finances.py, app_versions.py et manual.py dans GitHub.
2. Faire Commit changes.
3. Attendre le redéploiement Canner.
4. Faire Ctrl+F5.
5. Vérifier que Finances affiche V1.12.5.

TEST RECOMMANDÉ
---------------
1. Ouvrir Finances > Budget.
2. Noter le mois affiché et les montants.
3. Cliquer une fois sur la flèche du mois suivant.
4. Vérifier immédiatement, sans changer d’onglet, que :
   - le nom du mois change;
   - Disponible ce mois et le nombre de paies changent si nécessaire;
   - les sections Actives / À venir / Archives se recalculent;
   - la section Prévisions est recalculée.
5. Revenir au mois précédent et confirmer le même comportement.
