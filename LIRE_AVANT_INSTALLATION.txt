JF APPS — CORRECTIF PORTAIL V1.2.1

PROBLÈME

Après le développement groupé, la fonction principale index était encore
présente dans app.py, mais son décorateur NiceGUI @ui.page("/") avait été
retiré accidentellement.

Conséquence :
- NiceGUI démarrait correctement;
- aucune page n’était enregistrée à l’adresse /;
- Canner recevait / et /?tab=items, mais NiceGUI répondait 404 Not Found.

CORRECTION

La route suivante est restaurée dans app.py :

@ui.page(
    "/",
    title="JF Apps",
    language="fr",
)

La page principale et tous les onglets utilisant les paramètres ?tab=
fonctionnent de nouveau.

FICHIERS COMPLETS À REMPLACER

- app.py
- app_versions.py
- manual.py

INSTALLATION

1. Déposer les trois fichiers ensemble à la racine de GitHub.
2. Faire Commit changes.
3. Attendre le redémarrage complet de Canner.
4. Ouvrir l’adresse principale du site.
5. Faire Ctrl+F5 si le navigateur affiche encore l’ancienne page.
