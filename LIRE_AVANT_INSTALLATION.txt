NOUVEAUTÉS

1. EN-TÊTE COMMUN
Le Portail, Liste d’épicerie, Journal de pression, Finances,
Personnages JDR et Commentaires utilisent le même en-tête.

Il contient :
- le logo JF Apps;
- le nom de l’application;
- sa version;
- Portail;
- Commentaires;
- Aide;
- Mon compte;
- un menu pour Nouveautés, Installer JF Apps et Déconnexion.

2. BOUTON PORTAIL TOUJOURS VISIBLE
Le bouton Portail reste présent dans toutes les applications.
Le logo ramène aussi au Portail.

Le mode Courses conserve son affichage simplifié, mais reçoit maintenant
l’en-tête commun.

3. MENUS HARMONISÉS
Les onglets des applications utilisent les mêmes espacements,
tailles, couleurs et règles d’affichage mobile.

La liste d’épicerie conserve :
- sa barre inférieure Items / Besoins / Catégories / Portail;
- une barre locale Planification / Activité / Données.

4. VERSIONS
Versions affichées :
- Portail JF Apps V1.1.0
- Liste d’épicerie V1.0.0
- Journal de pression V1.0.0
- Finances V1.3.0
- Personnages JDR V1.0.0
- Commentaires et suggestions V1.0.0

La page Nouveautés présente maintenant une matrice des versions actuelles.

5. LOGO, FAVICON ET PWA
Le monogramme JF Apps est utilisé comme :
- favicon 32 et 64 pixels;
- icône Apple;
- icônes PWA 192 et 512 pixels;
- icône maskable;
- logo dans l’en-tête commun.

Le cache PWA est changé de version afin que les nouvelles icônes
puissent remplacer les anciennes.

INSTALLATION

1. Ouvrir le dépôt GitHub.
2. Choisir Add file > Upload files.
3. Déposer tous les fichiers énumérés dans « Fichiers complets à remplacer ».
4. Faire Commit changes.
5. Attendre la fin du déploiement Canner.
6. Sur ordinateur, faire Ctrl+F5.
7. Sur téléphone, fermer complètement la PWA puis la rouvrir.
8. Si l’ancienne icône reste visible, retirer le raccourci PWA puis
   réinstaller JF Apps depuis le menu de l’en-tête.
