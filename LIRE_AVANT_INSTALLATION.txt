JF APPS — FINANCES V1.0.0

Fichiers complets à déposer ENSEMBLE à la racine du dépôt GitHub :
- app.py
- app_access.py
- app_versions.py
- release_notes.py
- finances.py
- finances_data.py
- manual.py

NOUVELLE APPLICATION
Finances V1.0.0 comprend :
- dépenses et revenus manuels;
- saisie rapide compacte pour téléphone;
- catégories et sous-catégories;
- étiquettes multiples;
- transactions récurrentes paramétrables;
- occurrences à confirmer ou automatiques;
- objectifs mensuels par catégorie, sous-catégorie ou étiquette;
- report configurable : aucun, inutilisé, dépassement ou les deux;
- plafond de report facultatif;
- tableau de bord mensuel;
- historique compact et filtres;
- exportations CSV et JSON;
- confidentialité stricte par utilisateur.

VERSIONS ET ANNONCES
- Finances commence à V1.0.0.
- Une carte « Nouveautés et versions » est ajoutée au Portail.
- Les versions importantes sont définies dans app_versions.py.
- Leur présentation se trouve dans release_notes.py.
- Pour une petite correction invisible, il n’est pas nécessaire
  d’annoncer une nouvelle version.
- Pour une nouvelle fonction ou un changement important :
  incrémenter la version et ajouter une note de version.

CONVENTION RETENUE
- correction : 1.0.1;
- amélioration compatible : 1.1.0;
- changement majeur : 2.0.0.

BASE DE DONNÉES
Les tables Finances sont créées automatiquement.
Aucun script SQL manuel n’est nécessaire.
Aucune nouvelle dépendance Python n’est requise.

ACCÈS
L’application Finances devient disponible dans la gestion des accès.
L’administrateur y accède automatiquement.
Pour donner l’accès à un ami :
1. ouvrir Utilisateurs;
2. modifier l’utilisateur;
3. activer Finances;
4. enregistrer.

INSTALLATION
1. Ouvrir le dépôt GitHub.
2. Choisir Add file > Upload files.
3. Déposer les sept fichiers ensemble.
4. Faire Commit changes.
5. Attendre le déploiement Canner.
6. Actualiser avec Ctrl+F5 ou rouvrir la PWA.
7. Vérifier la carte Finances V1.0.0.
8. Tester une catégorie, une étiquette, une dépense,
   une récurrence, un objectif avec report et les deux exportations.

IMPORTANT
Cette V1 prépare une évolution vers une comptabilité complète
en V3 ou V4, mais n’affiche pas encore les comptes bancaires,
rapprochements, transferts ou écritures comptables.

VÉRIFICATIONS EFFECTUÉES

- initialisation automatique du schéma;
