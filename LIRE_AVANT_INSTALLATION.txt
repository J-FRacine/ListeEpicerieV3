JF APPS — FINANCES V1.12.2 — CORRECTIF DE DÉMARRAGE

PROBLÈME CORRIGÉ
----------------
Finances V1.12.1 pouvait encore afficher une erreur 500 au lancement :
NameError: name 'user' is not defined

Le nouvel onglet Prêts partagés appelait :
shared_loans_panel(user, ...)
alors que finances_panel reçoit l’utilisateur sous le nom current_user.

CORRECTION
----------
Le module reçoit maintenant current_user. Le callback de rafraîchissement demeure différé, ce qui conserve aussi le correctif V1.12.1.

FICHIERS À REMPLACER
--------------------
- finances.py
- app_versions.py
- manual.py

Les fichiers finances_data.py et finances_shared_loans.py sont inclus dans le paquet pour cohérence mais sont inchangés depuis V1.12.1.

INSTALLATION
------------
1. Remplacer finances.py, app_versions.py et manual.py dans GitHub.
2. Commit changes.
3. Laisser Canner redéployer.
4. Faire Ctrl+F5.
5. Vérifier que Finances affiche V1.12.2 et ouvre le Tableau sans erreur 500.
6. Ouvrir ensuite l’onglet Prêts partagés pour confirmer son affichage.
