Aucune donnée existante n’est modifiée.

NOUVELLE OPTION
Dans Journal de pression > Rapport PDF, une case permet maintenant de choisir :
- désactivée (par défaut) : l’heure exacte demeure affichée;
- activée : l’heure est remplacée par « Matin » ou « Soir ».

RÈGLE UTILISÉE
- avant 12:00 : Matin;
- à partir de 12:00 : Soir.

L’heure exacte reste enregistrée dans PostgreSQL et continue d’apparaître dans l’historique, le CSV et le JSON. Seule la présentation du PDF change.

Les notes du PDF utilisent le même libellé lorsque l’option Matin / Soir est activée.

VERSION
Journal de pression : V1.2.1

INSTALLATION
1. Ouvrir le dépôt GitHub JF Apps.
2. Choisir Add file > Upload files.
3. Déposer les 4 fichiers Python ensemble.
4. Faire Commit changes.
5. Attendre le redéploiement complet de Canner.
6. Sur ordinateur : Ctrl+F5.
7. Sur téléphone/PWA : fermer complètement JF Apps puis la rouvrir.
8. Vérifier que Journal de pression affiche V1.2.1.

TEST RAPIDE
1. Ouvrir Journal de pression > Rapport PDF.
2. Générer un PDF sans cocher l’option : les heures exactes doivent apparaître.
3. Cocher « Afficher Matin / Soir plutôt que l’heure exacte ».
4. Générer de nouveau le PDF.
5. Une mesure avant midi doit afficher « Matin ».
6. Une mesure à midi ou après doit afficher « Soir ».
7. Vérifier qu’une note éventuelle utilise aussi Matin / Soir.
