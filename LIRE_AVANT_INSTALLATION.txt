JF APPS — PORTAIL V1.3.3 — STATISTIQUES CANNER WEB VITALS
==========================================================

OBJECTIF
--------
Canner demande d'ajouter le script suivant afin d'alimenter ses statistiques
techniques / Web Vitals :

<script src="https://api.canner.ca/_canner/vitals.js" async></script>

INTÉGRATION
-----------
Le script est ajouté dans app.py avec ui.add_head_html(..., shared=True).
Il est donc injecté dans le <head> commun de JF Apps et chargé de façon
asynchrone sur toutes les pages.

FICHIERS À REMPLACER ENSEMBLE
-----------------------------
- app.py
- app_versions.py
- manual.py

INSTALLATION
------------
1. Dans GitHub, remplacer les 3 fichiers ci-dessus.
2. Faire Commit changes.
3. Laisser Canner redéployer.
4. Faire Ctrl+F5 sur ordinateur après le redéploiement.
5. Vérifier que le Portail affiche V1.3.3.
6. Après quelques visites/pages, vérifier dans Canner que les statistiques
   commencent à recevoir des données. Le délai d'affichage éventuel dépend de Canner.
