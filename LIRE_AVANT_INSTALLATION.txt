JF APPS — FINANCES V1.12.1 — CORRECTIF DE DÉMARRAGE
=====================================================

PROBLÈME CORRIGÉ
----------------
Finances V1.12.0 pouvait échouer dès l'ouverture avec une erreur indiquant que
la variable locale `refresh_all` était utilisée avant d'être définie.

La cause se trouvait dans le nouvel onglet « Prêts partagés » : pendant la
construction de l'écran, le code transmettait directement `refresh_all` à
`shared_loans_panel`, alors que cette fonction de rafraîchissement est définie
plus bas dans `finances_panel`.

CORRECTION
----------
Le callback de rafraîchissement est maintenant transmis sous forme différée :
`lambda: refresh_all()`.

Il n'est donc résolu que lorsqu'un rafraîchissement est réellement demandé,
après la construction complète de l'écran.

Aucune fonction de Finances V1.12.0 n'est retirée ou modifiée autrement.

FICHIERS À REMPLACER
--------------------
À la racine du dépôt GitHub :

- finances.py       (remplacer — correctif principal)
- app_versions.py   (remplacer — Finances passe à V1.12.1)
- manual.py         (remplacer — documentation du correctif)

Le paquet contient aussi, inchangés par rapport à V1.12.0 :

- finances_data.py
- finances_shared_loans.py

Si ces deux fichiers V1.12.0 sont déjà présents dans GitHub, il n'est pas
nécessaire de les remplacer. Ils sont inclus dans le ZIP pour conserver un
paquet Finances complet et cohérent.

INSTALLATION
------------
1. Dans GitHub, remplacer finances.py, app_versions.py et manual.py.
2. Vérifier que finances_shared_loans.py de V1.12.0 est toujours présent.
3. Faire Commit changes.
4. Laisser Canner redéployer.
5. Ouvrir JF Apps puis Finances.
6. Vérifier que Finances affiche V1.12.1.
7. Ouvrir aussi l'onglet « Prêts partagés ».
