============================================================
FINANCES V1.5.0
============================================================

TABLEAU — KPI CLIQUABLES
- Le nom d’une catégorie ou d’une étiquette est maintenant cliquable.
- La fenêtre de détail montre les transactions du mois affiché.
- Réalisé, À venir et Total prévu sont séparés.
- Une transaction réelle peut ouvrir sa fiche.
- Une récurrence seulement projetée demeure consultative.

SAISIE RAPIDE — NOUVELLE CATÉGORIE
- La liste Catégorie contient « + Ajouter une catégorie… ».
- On peut créer une catégorie principale.
- On peut choisir une catégorie principale existante afin de créer une
  sous-catégorie.
- La nouvelle catégorie est automatiquement sélectionnée.

SAISIE RAPIDE — NOUVELLE ÉTIQUETTE
- La liste Étiquettes contient « + Ajouter une étiquette… ».
- Les étiquettes déjà sélectionnées sont conservées.
- La nouvelle étiquette est automatiquement ajoutée à la transaction.

DOUBLONS
- La vérification ignore la casse, les accents et les espaces superflus.
- Un élément existant est réutilisé plutôt que dupliqué.
- Un élément correspondant mais désactivé est réactivé.

============================================================
JOURNAL DE PRESSION V1.2.0
============================================================

MOYENNES
Dans Historique, la plage de dates choisie sert aussi au calcul :
- moyenne systolique;
- moyenne diastolique;
- moyenne du pouls;
- nombre de mesures utilisées.

Toutes les mesures réellement enregistrées dans l’intervalle sont utilisées.
Une journée sans mesure n’ajoute aucune valeur fictive.

RAPPELS PAR PRISE
Chaque prise possède maintenant :
- Nom;
- Début;
- Fin;
- Avis appareil à;
- Notification sur l’appareil activée/désactivée.

La règle actuelle est conservée :
les mesures de la journée sont associées chronologiquement aux prises prévues.

NOTIFICATIONS WEB PUSH
Dans Rappel :
- « Activer sur cet appareil »;
- « Désactiver sur cet appareil ».

Le navigateur demande l’autorisation de notification.
Le fuseau horaire est enregistré par appareil.
Avant tout envoi, le serveur revérifie les mesures de la journée.
Le contrôle s’effectue environ toutes les 5 minutes.

Le texte envoyé reste volontairement générique :
Journal de pression
Une mesure est prévue.

Aucune valeur de pression ou de pouls n’apparaît dans la notification.

Si plusieurs anciens rappels deviennent dus à la fois après une interruption,
seul le rappel dû le plus récent est envoyé.

Sur iPhone/iPad, tester depuis JF Apps ajoutée à l’écran d’accueil et après
avoir autorisé les notifications.

SAUVEGARDE JSON
Les réglages de notification de chaque prise sont maintenant inclus :
- activation;
- heure de notification.

============================================================
INSTALLATION
============================================================

1. Ouvrir le dépôt GitHub JF Apps.
2. Choisir Add file > Upload files.
3. Déposer les 10 fichiers ensemble.
4. Vérifier que le NOUVEAU fichier blood_pressure_push.py est présent.
5. Faire Commit changes.
6. Attendre le redéploiement complet de Canner.
7. Attendre aussi l’installation de pywebpush.
8. Sur ordinateur : Ctrl+F5.
9. Sur téléphone/PWA : fermer complètement JF Apps puis la rouvrir.
10. Vérifier les versions :
    - Finances V1.5.0
    - Journal de pression V1.2.0

============================================================
TESTS — JOURNAL DE PRESSION
============================================================

MOYENNES
1. Historique : choisir une plage contenant plusieurs mesures.
2. Vérifier les trois moyennes et le nombre de mesures.
3. Tester une plage sans mesure.

NOTIFICATION
1. Rappel : conserver les rappels généraux actifs.
2. Pour une prise de test, activer Notification sur l’appareil.
3. Mettre Avis appareil à une heure déjà atteinte ou très proche.
4. Enregistrer les réglages.
5. Cliquer Activer sur cet appareil.
6. Autoriser les notifications.
7. Ne pas enregistrer la mesure correspondante.
8. Attendre le prochain contrôle serveur (normalement au plus quelques minutes).
9. Vérifier la notification « Journal de pression — Une mesure est prévue. »
10. Toucher la notification et vérifier l’ouverture de JF Apps.

ANTI-NOTIFICATION INUTILE
1. Configurer une autre heure de test.
2. Saisir la mesure avant cette heure.
3. Vérifier qu’aucune notification n’est envoyée pour cette prise.

DÉSACTIVATION
1. Cliquer Désactiver sur cet appareil.
2. Vérifier la confirmation.
