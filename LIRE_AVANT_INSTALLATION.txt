PORTAIL JF APPS V1.2.0
============================================================

CORRECTION DE L’EN-TÊTE MOBILE

Sur téléphone, l’en-tête contient maintenant seulement :
- le logo;
- le nom de l’application;
- la version;
- le bouton Portail;
- le menu Plus.

Le menu Plus contient :
- Commentaires;
- Aide;
- Mon compte;
- Nouveautés et versions;
- Installer JF Apps;
- Déconnexion.

Le compteur de commentaires non lus apparaît sur le menu Plus.

Sur ordinateur, l’en-tête complet demeure disponible.

NAVIGATION INFÉRIEURE DE L’ÉPICERIE

Le bouton Portail est retiré de la barre inférieure, puisqu’il est déjà
disponible dans l’en-tête.

La barre contient maintenant une seule ligne :
- Items;
- Besoins;
- Catégories, ou Magasins lorsque les catégories sont désactivées.

VERSIONS ET NOUVEAUTÉS

La matrice centrale affiche maintenant :
- Portail V1.2.0;
- Liste d’épicerie V1.1.0;
- Finances V1.4.0;
- les versions actuelles des autres applications.

============================================================
LISTE D’ÉPICERIE V1.1.0
============================================================

TRI SANS ACCENTS

Le tri alphabétique utilise une clé insensible à la casse et aux accents.

Exemple attendu :
- Café;
- Cafe;
- Céréales;
- Concombre.

L’orthographe originale reste affichée.

CATÉGORIES FACULTATIVES PAR FAMILLE

Dans Organisation, un interrupteur « Utiliser les catégories » permet
d’activer ou désactiver cette fonction pour toute la famille.

Lorsqu’elles sont désactivées :
- les champs de catégorie sont masqués dans Items;
- le tri et la recherche par catégorie sont masqués;
- Besoins est regroupé directement par magasin;
- Mode courses est regroupé directement par magasin;
- la navigation du bas affiche Magasins;
- les catégories et associations existantes sont conservées;
- les autres familles ne sont pas touchées;
- une réactivation restaure les anciennes catégories.

Les nouveaux items utilisent une catégorie technique « Sans catégorie »
qui demeure invisible tant que la fonction est désactivée.

============================================================
FINANCES V1.4.0
============================================================

RÉCURRENCES FUTURES

Les dépenses et revenus récurrents sont projetés jusqu’à la fin du mois
affiché dans le Tableau, même si leur date n’est pas encore atteinte.

La projection n’insère pas immédiatement une transaction confirmée et ne
modifie pas le calendrier réel de la récurrence.

RÉALISÉ / À VENIR / TOTAL PRÉVU

Le Tableau distingue maintenant :
- Réalisé : transactions confirmées dont la date est atteinte;
- À venir : transactions prévues, postdatées ou récurrentes futures;
- Total prévu : Réalisé + À venir.

TRANSACTIONS À VENIR

Une section présente :
- les dépenses à venir;
- les revenus à venir;
- l’effet net prévu;
- la date;
- la description;
- le mode de paiement;
- Récurrence projetée ou À confirmer.

KPI

Les KPI des dépenses et des revenus présentent :
- le nom de la catégorie ou de l’étiquette;
- Réalisé;
- À venir;
- Total prévu.

Les montants sont alignés à droite.
Le Total prévu est visuellement plus marqué.
Les noms trop longs sont tronqués et leur texte complet est accessible
au survol.

Une transaction portant plusieurs étiquettes peut apparaître dans
plusieurs lignes. Les totaux d’étiquettes ne doivent pas être additionnés
pour obtenir le total général.

OBJECTIFS

Une transaction postdatée n’est plus incluse dans le montant réalisé
d’un objectif avant que sa date soit atteinte.

============================================================
INSTALLATION
============================================================

1. Ouvrir le dépôt GitHub.
2. Choisir Add file > Upload files.
3. Déposer les onze fichiers ensemble.
4. Faire Commit changes.
5. Attendre la fin du déploiement Canner.
6. Sur ordinateur, recharger avec Ctrl+F5.
7. Sur téléphone, fermer complètement la PWA puis la rouvrir.

============================================================
TESTS RECOMMANDÉS
============================================================

PORTAIL MOBILE
1. Ouvrir chaque application sur téléphone.
2. Vérifier qu’aucun libellé ne se chevauche.
3. Tester Portail et le menu Plus.
4. Vérifier le compteur de commentaires.

ÉPICERIE
1. Trier Café, Céréales et Concombre par ordre alphabétique.
2. Ouvrir Organisation.
3. Désactiver Utiliser les catégories.
4. Vérifier Items, Besoins et Mode courses.
5. Ajouter un item sans catégorie visible.
6. Réactiver les catégories et vérifier que les anciennes associations
   sont toujours présentes.

FINANCES
1. Créer une récurrence future dans le mois affiché.
2. Vérifier son apparition dans Transactions à venir.
3. Vérifier Réalisé, À venir et Total prévu.
4. Vérifier les KPI par catégorie et étiquette.
5. Vérifier séparément les revenus et les dépenses.
6. Changer de mois et vérifier la projection des récurrences.
