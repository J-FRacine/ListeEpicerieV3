============================================================
1. BUDGET LIÉ AUX RÉCURRENCES
============================================================

Dans Budget > Ajouter/Modifier un poste :
- choisir facultativement une « Récurrence associée »;
- activer « Synchroniser automatiquement le montant avec la récurrence ».

Quand la synchronisation est active :
- une récurrence mensuelle alimente le montant mensuel;
- une récurrence toutes les 2 semaines alimente le montant aux deux semaines;
- les autres fréquences sont converties en moyenne mensuelle;
- une modification ultérieure du montant ou de la fréquence de la récurrence
  met à jour le poste Budget lié;
- le montant par paie personnalisé reste disponible pour une ligne mensuelle.

Une même récurrence ne peut être liée qu’à un seul poste Budget.
Les postes sans transaction précise peuvent rester « Budget seulement ».

============================================================
2. TRANSACTION PROGRAMMÉE À LA BANQUE
============================================================

Pour une transaction Prévue ou une récurrence :
- cocher « Programmée dans le compte bancaire » lorsque le paiement/mouvement
  a déjà été planifié auprès de la banque;
- l’élément reste Prévu dans JF Apps jusqu’à confirmation;
- l’indicateur apparaît dans Compte, Historique et Récurrences.

Pour une transaction déjà Confirmée, cet indicateur n’est pas conservé.

============================================================
3. RAPPELS DE TRANSACTIONS
============================================================

Pour une transaction Prévue :
- cocher « Me rappeler cette transaction le jour prévu »;
- choisir l’heure du rappel (09:00 par défaut).

Pour une récurrence :
- cocher « Me rappeler chaque occurrence le jour prévu »;
- choisir l’heure du rappel.

Règles :
- la notification est envoyée le jour prévu selon le fuseau horaire de l’appareil;
- si la transaction a déjà été confirmée, le rappel n’est pas envoyé;
- une récurrence peut être rappelée même si son occurrence n’a pas encore été
  matérialisée dans l’Historique;
- si une occurrence matérialisée existe, ses réglages prennent priorité;
- un seul rappel est enregistré par transaction/récurrence, date et appareil.

Texte volontairement discret :
Finances
Une transaction prévue nécessite votre attention.

Le clic ouvre Finances > Historique.

============================================================
4. ACTIVATION SUR L’APPAREIL
============================================================

Dans Finances > Compte :
- « Activer sur cet appareil »;
- « Désactiver sur cet appareil ».

Le Web Push de JF Apps est partagé techniquement, mais les canaux sont séparés :
- canal Journal de pression;
- canal Finances.

Donc désactiver les rappels Finances ne désactive pas ceux du Journal de pression.

Sur iPhone/iPad : utiliser JF Apps ajoutée à l’écran d’accueil et autoriser les
notifications, comme pour Journal de pression.

============================================================
5. EXPORT / SAUVEGARDE
============================================================

CSV et JSON des transactions contiennent maintenant :
- Programmée à la banque;
- Rappel actif;
- Heure du rappel.

Le JSON continue aussi de contenir les récurrences et les postes Budget.

============================================================
INSTALLATION
============================================================

1. GitHub > Add file > Upload files.
2. Déposer les 6 fichiers .py ensemble à la racine du dépôt.
3. Faire Commit changes.
4. Attendre le redéploiement Canner.
5. Sur ordinateur : Ctrl+F5.
6. Sur téléphone/PWA : fermer complètement JF Apps puis la rouvrir.
7. Vérifier que Finances affiche V1.6.1.

============================================================
TESTS RECOMMANDÉS APRÈS DÉPLOIEMENT
============================================================

A. Budget lié
1. Créer ou choisir une récurrence mensuelle de test.
2. Lier un poste Budget à cette récurrence avec synchronisation active.
3. Modifier le montant de la récurrence.
4. Vérifier que le montant Budget suit la modification.

B. Programmée à la banque
1. Créer une transaction future avec statut Prévue.
2. Cocher Programmée dans le compte bancaire.
3. Vérifier le libellé dans Compte et Historique.

C. Notification
1. Dans Compte, cliquer Activer sur cet appareil et autoriser les notifications.
2. Créer une transaction Prévue pour aujourd’hui.
3. Activer le rappel et choisir une heure déjà atteinte ou très proche.
4. Laisser la transaction Prévue.
5. Le contrôle serveur s’effectue environ toutes les 5 minutes.
6. Vérifier la notification Finances.
7. Refaire le test en confirmant la transaction avant l’heure : aucun rappel ne
   doit être envoyé.

D. Canaux indépendants
1. Si Journal de pression est aussi activé, désactiver Finances sur l’appareil.
2. Vérifier que le Journal de pression conserve son canal de notification.
