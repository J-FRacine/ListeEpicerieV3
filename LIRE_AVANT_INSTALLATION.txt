JF APPS — FINANCES V1.1.0 — IMPORTATION

Fichiers complets à remplacer à la racine de GitHub :
- finances.py
- finances_data.py
- app_versions.py
- manual.py

Fichier de données prêt à importer :
- spendee_90_jours_pret_pour_jf_apps.csv

INSTALLATION DU CODE
1. GitHub > Add file > Upload files.
2. Déposer les quatre fichiers Python ensemble.
3. Faire Commit changes.
4. Attendre le déploiement Canner.
5. Actualiser complètement avec Ctrl+F5 ou rouvrir la PWA.
6. La carte Finances doit afficher V1.1.0.

IMPORTATION DES DONNÉES
1. Ouvrir Finances.
2. Ouvrir l’onglet Exporter.
3. Dans Importer des transactions, choisir :
   spendee_90_jours_pret_pour_jf_apps.csv
4. Vérifier la prévisualisation.
5. Laisser cochée l’option qui ignore les transactions identiques.
6. Cliquer sur Importer.

Le fichier Spendee original peut aussi être sélectionné directement.
Le fichier transformé est fourni pour rendre les données faciles à lire
et pour figer la conversion des dates au fuseau America/Toronto.

PROTECTIONS
- prévisualisation obligatoire;
- détection des clés déjà importées;
- détection des transactions identiques déjà présentes;
- création automatique des catégories et étiquettes;
- erreurs de lignes affichées sans bloquer les autres lignes;
- aucune suppression des données existantes.

BASE DE DONNÉES
Trois colonnes sont ajoutées automatiquement à finance_transactions :
- import_source;
- import_key;
- imported_at.

Aucun script SQL manuel.
Aucune nouvelle dépendance Python.
