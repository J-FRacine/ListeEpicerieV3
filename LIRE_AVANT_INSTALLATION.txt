JF APPS — FINANCES V1.13.0 — REFACTORISATION ET STABILITÉ
Date : 31 août 2026

OBJECTIF
--------
Cette version ne cherche pas à ajouter une grosse fonction. Elle remet en ordre
le code de Finances après les nombreuses évolutions V1.6 à V1.12 afin de réduire
les régressions et de rendre les prochains développements plus simples.

AUCUNE DONNÉE N'EST SUPPRIMÉE.
AUCUN SCRIPT SQL MANUEL.
AUCUNE NOUVELLE DÉPENDANCE PYTHON.
AUCUN CHANGEMENT DE SCHÉMA POSTGRESQL.

BASE UTILISÉE
-------------
Finances V1.12.6, incluant les correctifs V1.12.1 à V1.12.6 et les fonctions de
V1.12.0 : Budget/Prévisions, groupes de financements, intérêts, KPI, Prêts
partagés, Historique, conciliations en cours, etc.

CE QUI A ÉTÉ REFACTORISÉ
------------------------
1. Calculs purs centralisés dans finances_calculations.py :
   - dates et décalages mensuels;
   - prochaines occurrences de récurrence;
   - paies aux deux semaines;
   - estimation de progression des financements;
   - calcul amorti des versements avec intérêts.

2. Validations communes centralisées dans finances_validation.py :
   - montants;
   - décimales;
   - textes;
   - dates facultatives.

3. Données des Prêts partagés séparées dans finances_shared_loans_data.py.
   L'interface reste dans finances_shared_loans.py.

4. Navigation mensuelle centralisée dans finances_ui_state.py avec MonthCursor.
   Budget, Tableau, Compte et Financements ne manipulent plus chacun un petit
   dictionnaire de mois différent.

5. finances_data.py ne redéfinit plus plusieurs fois les mêmes fonctions sous le
   même nom. Les implémentations historiques encore nécessaires portent un nom
   versionné explicite et les anciennes versions mortes ont été supprimées.

6. Budget et Financements utilisent chacun un composant NiceGUI @ui.refreshable
   autonome. Le mélange d'un conteneur externe .clear() avec refreshable a été
   retiré des deux vues mensuelles.

INSTALLATION
------------
1. Faire une sauvegarde globale depuis le Centre de maintenance avant le commit.
2. Remplacer les 5 fichiers indiqués plus haut.
3. Ajouter les 4 nouveaux modules à la racine du dépôt.
4. Faire le commit GitHub et attendre le redéploiement Canner.
5. Faire Ctrl+F5 sur ordinateur après le déploiement.
6. Vérifier que Finances affiche V1.13.0.

TESTS CONSEILLÉS APRÈS DÉPLOIEMENT
---------------------------------
A. Ouverture
- Ouvrir Finances puis chaque onglet au moins une fois.
- Ouvrir Prêts partagés pour confirmer que le module charge normalement.

B. Budget / mois
- Dans Budget, changer de mois avec les flèches.
- Le libellé et les KPI doivent changer immédiatement.
- Octobre 2026 doit indiquer 3 paies dans le cas de référence déjà configuré.

C. Financements
- Changer de mois avec les flèches.
- Septembre 2026 doit additionner les échéances du 5 septembre.
- Vérifier que le total des soldes restants reste cohérent.

D. Opérations courantes
- Ajouter/modifier une petite transaction de test puis la supprimer.
- Ouvrir Historique, Tableau et Conciliation.
- Vérifier qu'aucune donnée existante n'a changé.

RETOUR ARRIÈRE
--------------
Cette version ne modifie pas le schéma de la base. En cas de problème d'interface,
il est donc possible de remettre les fichiers V1.12.6 sans migration inverse.
