JF APPS — PORTAIL V1.4.0
RESTAURATION GLOBALE SÉLECTIVE + STATISTIQUES CANNER
Date : 31 août 2026

OBJECTIF
--------
Cette livraison concerne le Portail JF Apps. Elle conserve Finances V1.13.1 et
les versions actuelles des autres applications.

NOUVEAUTÉS
----------
1. Centre de maintenance — restauration globale sélective
   - chargement d'une archive ZIP créée par « Sauvegarder toutes mes données »;
   - validation du manifest et de la structure avant toute écriture;
   - prévisualisation du contenu de chaque application;
   - choix des applications à restaurer individuellement;
   - possibilité de restaurer uniquement Finances, par exemple, sans toucher aux
     autres applications;
   - pour Liste d'épicerie, choix de la famille de destination pour chacune des
     familles présentes dans l'archive;
   - restauration par fusion non destructive : aucune donnée actuelle n'est
     supprimée automatiquement;
   - doublons reconnus ignorés selon les règles de chaque application;
   - respect des droits d'accès actuels de l'utilisateur.

2. Sauvegarde globale V2
   - le manifest indique maintenant que la restauration sélective est disponible;
   - les familles de Liste d'épicerie possèdent un chemin explicite et leur
     identifiant source dans le manifest;
   - les anciennes archives globales V1 restent acceptées par la restauration.

3. Statistiques Canner
   Le script suivant est ajouté une seule fois dans le <head> partagé, en plus
   du script Web Vitals déjà installé :

   <script defer src="https://canner.ca/t.js"
           data-site-id="2dd1f6d1-013b-4ec9-a990-4770b46f3277"
           data-domains="liste-jfr-v1.canner.app"></script>

INSTALLATION
------------
1. Faire une sauvegarde de sécurité de l'installation actuellement en ligne.
2. Dans GitHub, remplacer les quatre fichiers indiqués ci-dessus.
3. Ajouter global_restore.py à la racine, au même niveau que app.py.
4. Faire Commit changes.
5. Laisser Canner terminer le redéploiement.
6. Faire Ctrl+F5 sur ordinateur si l'ancienne interface reste en cache.
7. Vérifier que le Portail affiche V1.4.0 et Finances V1.13.1.

TESTS CONSEILLÉS APRÈS DÉPLOIEMENT
---------------------------------
A. Nouvelle sauvegarde
1. Ouvrir Portail > Centre de maintenance.
2. Cliquer « Créer la sauvegarde ».
3. Conserver le ZIP obtenu comme sauvegarde de test.

B. Prévisualisation sans restauration
1. Dans « Restauration globale », charger le ZIP de test.
2. Vérifier que le Portail affiche les applications présentes.
3. Vérifier qu'aucune donnée n'est modifiée à cette étape.
4. Décocher toutes les applications sauf une application de test.

C. Restauration sélective
1. Choisir une application dont les données existent déjà.
2. Lancer « Restaurer la sélection ».
3. Vérifier que les doublons connus ne sont pas recréés.
4. Vérifier que les autres applications non cochées n'ont pas été modifiées.

D. Liste d'épicerie
1. Charger une sauvegarde contenant une ou plusieurs familles.
2. Vérifier que chaque famille source peut être activée/désactivée et associée
   seulement à une famille actuellement accessible au compte.

E. Finances
La restauration Finances est une fusion non destructive. Elle restaure les
transactions et postes Budget compatibles ainsi que les modules complémentaires
pris en charge (financements, groupes de financements et prêts partagés). Elle
ne supprime pas les données actuelles et évite les doublons reconnus.

SÉCURITÉ
--------
- Archives acceptées : sauvegardes globales JF Apps V1 et V2 seulement.
- Taille ZIP maximale : 40 Mo.
- Taille décompressée maximale : 120 Mo.
- Protection contre les chemins ZIP non sécuritaires (« ../ » etc.).
- Une application non autorisée pour le compte n'est pas restaurable.
- Une famille d'épicerie devenue inaccessible n'est pas restaurable.
- Aucun remplacement global destructif n'est proposé dans cette version.
